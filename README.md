# 🚌 "Buýt Xanh" App

A mobile application that helps passengers search bus routes and navigate easily in Hanoi.
The app allows users to find routes, view bus information, track stops on a map, and receive notifications when approaching their destination.

# 🚀 Features

Search bus routes from point A → B

View bus route information and schedules

Display bus stops on Google Maps

Receive notifications when approaching a stop

Save favorite routes

Entertainment features during the trip (music / games)

Offline route lookup

These features help improve the experience of using public bus transportation.

# 🛠 Tech Stack

Flutter – Mobile application

Spring Boot – Backend REST API

MySQL – Database

Google Maps API – Map and route services

The system follows a client–server architecture where the mobile app communicates with backend services through APIs.

# 🏗 System Architecture
Mobile App (Flutter)
        ↓
REST API
        ↓
Backend (Spring Boot)
        ↓
Database (MySQL)
        ↓
Google Maps API
